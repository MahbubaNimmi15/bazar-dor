# 🛒 BazarDor | বাজার দর

**BazarDor (বাজার দর)** is a modern, responsive, and user-friendly daily market price web application designed for users in Bangladesh. The main goal of this project is to make essential commodity price information easy to access, understand, and compare from a single platform.

Users can browse a wide range of daily market products such as rice, lentils, oil, vegetables, fish, meat, eggs, milk, and spices. Product prices are displayed clearly with Bengali numerals, units, and daily price-change indicators so that users can quickly understand whether a product's price has increased, decreased, or remained unchanged.

The home page highlights the **Top 6 price risers**, **Top 6 price fallers**, and a complete list of available products. Users can also browse products by category and sort them by price using options such as **Default**, **Low to High**, and **High to Low**.

Each product has a dedicated details page where authenticated users can view important information including the product name, category, unit, current price, minimum price, maximum price, average price, and market-wise price information.

The application includes a complete authentication system powered by **Better Auth**. Users can create an account using their name, email, and password, sign in securely, use supported social authentication methods, access protected routes, view their profile, and update their personal information.

BazarDor also provides helpful user-experience features such as **toast notifications**, **skeleton loading states**, **custom 404 pages**, protected-route redirects, an infinite scrolling market price ticker, and responsive layouts for mobile, tablet, laptop, and desktop devices.

The project is built with **Next.js, App Router, React, TypeScript, Tailwind CSS, Better Auth, PostgreSQL, and Neon**, and it is deployed on **Vercel** for public access.

1. Responsive design for mobile, tablet, and desktop
2. Category-wise product filtering
3. Price sorting: default, low to high, and high to low
4. Protected product details page
5. Email/password, Google, and GitHub authentication
6. Loading skeleton and custom 404 page
7. User profile and Update Information feature
8. Toast notifications for login, signup, logout, and validation
